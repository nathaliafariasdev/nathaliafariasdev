### Featured Projects

#### 🛰️ [Sampa Ar — Intelligent Air Quality Monitoring](https://github.com/nathaliafariasdev/qualidadedoar)
Spatiotemporal machine learning platform that estimates **PM2.5 and PM10** concentrations across all **645 municipalities in São Paulo**.
* **Methodology:** Combines tropospheric delay data from **GNSS (RBMC/IBGE)** stations with a hybrid **CNN-LSTM** deep learning architecture and **IDW** spatial interpolation.
* **Impact:** Provides continuous air quality coverage even in regions without physical environmental monitoring stations.

#### ☄️ [Asteroid Classification — NASA Data Analysis](https://github.com/nathaliafariasdev/classificacao_asteroides)
Comparative machine learning pipeline applied to **NASA astronomical datasets** for orbital object analysis and classification.
* **Methodology:** Exploratory data analysis, feature engineering, class balancing, and benchmarking of supervised learning models.
* **Goal:** Identify patterns in orbital parameters to accurately classify potentially hazardous near-Earth objects.
